# AMIS1013 Systems Analysis and Design
B2B Sales & Order Management System — Systems Analysis & Design

A complete Systems Analysis and Design (SAD) project report modeled after an enterprise electronics distributor (Samex Electronic).

### Overview
This project documents the end-to-end systems planning, analysis, and design phases for a B2B sales ordering platform. It addresses common operational issues like manual data entry errors, quotation-to-order bottlenecks, and payment gateway timeouts.

### Key Deliverables
* **System Planning & Feasibility:** Cost-benefit analysis, hardware/software budgeting, and tangible ROI estimations.
* **Process Modeling:** Context Diagram and Level-0 DFD mapping data flows across customer ordering, quotation, inventory, and payment subsystems.
* **Database & Data Architecture:** Entity-Relationship Diagrams (ERD), resolved Many-to-Many relationships, table data dictionaries, and derivation primary key coding.
* **UI/UX & Validation:** Add-to-cart interface design with built-in validation checks (range, format, presence, and limit checks).
* **Management Reporting:** Design of summary sales reports and exception reports for orders delayed beyond 48 hours.
